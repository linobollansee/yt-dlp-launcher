# yt-dlp-loop

A lightweight Windows batch script for repeatedly downloading videos using [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## Features

- Prompts you to enter a video URL.
- Starts each download in a minimized window.
- Automatically prompts for the next URL.
- Uses `yt-dlp` to handle video downloads.

## Requirements

- Windows
- [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) installed and available in your system's `PATH`.

## Usage

1. Download or clone this repository.
2. Make sure `yt-dlp` is installed and accessible from the command line.
3. Run the batch script.
4. Enter a video URL when prompted.
5. Repeat for as many videos as you want.

## How It Works

The script updates `yt-dlp`, then continuously prompts for URLs and starts a separate, minimized download process for each one.
